# Prodigy SAT

SAT prep tool with practice questions, score tracking, and study strategies.

## What It Does

Prodigy SAT helps students prepare for the SAT exam with interactive practice questions, performance analytics, and personalized study recommendations.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Features:** LocalStorage for progress tracking

## Features

- Practice questions across all SAT sections
- Score tracking and progress visualization
- Timed practice modes
- Answer explanations
- Performance analytics

## Getting Started

Open `index.html` in a web browser to start practicing.

## How It Works

The app presents SAT-style questions, tracks your answers, calculates scores, and shows performance trends over time to help identify areas for improvement.
